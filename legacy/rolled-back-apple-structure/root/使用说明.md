# 旅行单词 · 使用说明

这是一个面向真实旅行场景的日语与英语词汇学习 PWA。项目使用原生 HTML、CSS 和 JavaScript，不需要框架、构建工具、数据库或第三方运行时依赖。

## 当前产品结构

首次打开时选择日语或英语，选择结果保存在当前浏览器。完成后可以通过固定导航访问：

- **学习**：旅行基础入口和八个旅行场景。
- **自测**：当前保留产品结构，旧版记录仍可读取，练习模式后续接入。
- **工具**：为快速翻译和紧急信息卡预留入口。
- **我的**：切换语言、查看或清除本地学习记录、查看安装方式。

页面使用 Hash 路由，例如 `#/learn/restaurant`。这种方式同时兼容 GitHub Pages 仓库子目录和未来的根域名部署，不需要服务器端路由配置。

## 内容目录

原始词库仍位于 `data.js`，数据结构、分类、稳定 ID 均未修改。`js/catalog.js` 在产品层建立新的旅行场景目录：

- 可直接使用：酒店住宿、餐厅用餐、购物、日常沟通、紧急情况。
- 需要人工整理：机场与入境、交通出行、景点游览、旅行基础。

需要整理的内容不会从旧分类机械改名，也不会复制词条填充。Restaurant 当前完整使用旧 `food` 分类的 96 条内容，其中包含 84 个词汇和 12 个短语。

## 发音

每条内容右侧有独立的发音按钮。应用优先播放已有文件：

```text
audio/ja/{词条ID}.mp3
audio/en/{词条ID}.mp3
```

文件播放失败时会尝试使用浏览器系统语音。现有音频文件名、目录和词条 ID 映射没有改变。

发音 MP3 不由 Service Worker 缓存，因此断网时不保证可播放，也没有离线音频下载功能。

## 本地数据与旧版兼容

以下旧版 localStorage key 会继续保留和读取：

- `travelVocab.stats.v1`
- `travelVocab.wrongIds.v1`
- `travelVocab.lang.v1`
- `travelVocab.installHintDismissed.v1`

新版增加 `travelVocab.onboarding.v1`，用于记录首次设置是否完成。旧的双语值不会被删除，但新版会要求用户明确选择日语或英语。

“清除学习记录”只删除统计和错题，不会改变语言或 onboarding 设置。

## 安装和离线范围

通过 GitHub Pages 或其他 HTTPS 地址打开后，可在支持 PWA 的浏览器中安装到桌面或主屏幕。桌面端本地测试可使用 `http://localhost`。

- Chrome/Edge 在满足安装条件后会显示安装操作。
- iPhone/iPad 需要在 Safari 中使用“分享 → 添加到主屏幕”。网页不能自动调出 iOS 的安装界面。
- `file://` 可以加载普通页面，但不能注册 Service Worker；推荐使用本地 HTTP 服务。

Service Worker 只预缓存 HTML、CSS、JavaScript、词库、Manifest 和图标。所有 `audio/` 请求都绕过 Service Worker。

## 更新策略

应用壳缓存使用版本名。修改预缓存文件后，应递增 `sw.js` 中的版本号。新 Service Worker 会在后台安装，并等待旧页面全部关闭后再启用，不会在用户使用过程中强制刷新。

## 本地预览与测试

在项目目录运行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。自动测试可运行：

```powershell
node --test
```

重构前的应用层源码保存在 `legacy/pre-structure-rebuild/`，原始词库、音频和图标没有复制，因为它们没有被修改。
