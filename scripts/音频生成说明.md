# 词库音频生成说明

该工具读取项目现有的 `data.js`，为每条词汇分别生成日语和英语 MP3。它不会修改 `data.js`、`app.js` 或网页界面，也不需要 API Key。

## 1. 安装依赖

请在 `travel-vocab-v2` 项目目录打开终端，然后运行：

```powershell
python -m pip install -r scripts/requirements-audio.txt
```

`edge-tts` 使用在线语音服务，因此生成时需要联网。

## 2. 先检查词库

这一步不会联网，也不会生成文件：

```powershell
python scripts/generate_audio.py --validate-only
```

当前应检查到 555 条词汇，且所有 ID 唯一。

## 3. 生成试听样本

```powershell
python scripts/generate_audio.py --test
```

试听模式只处理词库前 5 条，共生成：

- `audio/ja/airport_001.mp3` 至 `airport_005.mp3`
- `audio/en/airport_001.mp3` 至 `airport_005.mp3`

请先试听这些文件，确认音色和语速满意后再生成完整词库。

## 4. 生成完整词库

```powershell
python scripts/generate_audio.py --full
```

完整模式的目标是 555 个日语文件和 555 个英语文件：

```text
audio/
├─ ja/
│  ├─ airport_001.mp3
│  └─ ...
└─ en/
   ├─ airport_001.mp3
   └─ ...
```

脚本会跳过已有且非空的 MP3，所以网络中断后可以直接重复运行。失败的词条会在最后集中列出；再次运行即可只补齐缺少的文件。

## 5. 更换声音和语速

打开 `scripts/generate_audio.py`，在文件顶部修改这些设置：

```python
JAPANESE_VOICE = "ja-JP-NanamiNeural"
ENGLISH_VOICE = "en-US-JennyNeural"

RATE = "+0%"
VOLUME = "+0%"
PITCH = "+0Hz"
```

例如将 `RATE` 改为 `"-8%"` 可以让两种语言读得更慢。可用声音可以用以下命令查看：

```powershell
edge-tts --list-voices
```

选择日语声音时使用 `ja-JP-...Neural`，英语声音使用对应的 `en-US-...Neural`、`en-GB-...Neural` 等名称。

## 解析方式

当前 `data.js` 的每条原始数据都是单独一行的六字段数组：

```text
[id, 中文, 日文, 假名, 英文, 类型]
```

这些词条数组本身符合 JSON 语法。脚本逐行用 Python 标准库 `json` 解析，不使用 `eval`，也不执行 `data.js`。解析后还会检查：

- 总数是否为 555；
- 每条是否恰好有 6 个字符串字段；
- ID 是否唯一并适合作为文件名；
- 日文和英文字段是否非空；
- 类型是否为 `word` 或 `phrase`。

如果将来改变了词库的排版方式，脚本会明确报错而不是悄悄漏掉词条。
