# 词库音频生成说明

## 日语旅行认读教学音

教学音频从 `languages/jp-ja/beginner/audio.json` 读取，与正式词库音频分开保存在 `audio/ja/beginner/`。46 个基础音分别生成一段 MP3，平假名与对应片假名共用；新增的假名行示例、完整浊音/半浊音、特殊拼读和连续认读材料使清单共 92 段。文字和语速完全相同的正式词库音频继续原路径复用，不重复生成。

```powershell
python -X utf8 scripts/generate_audio.py --beginner-validate-only
python -X utf8 scripts/generate_audio.py --beginner-test
python -X utf8 scripts/generate_audio.py --beginner-full
```

## 美国英语旅行认读教学音

英语教学音使用 `en-US-JennyNeural`，清晰词音、慢速短句和自然语速分别按清单设置语速。先验证并生成 6 段试听：

```powershell
python -X utf8 scripts/generate_audio.py --english-beginner-validate-only
python -X utf8 scripts/generate_audio.py --english-beginner-test
```

试听 `audio/en/beginner/` 中的代表性单词、词组和双语速短句。确认后生成全部 54 段：

```powershell
python -X utf8 scripts/generate_audio.py --english-beginner-full
```

## 韩国韩语旅行认读教学音

韩语教学音使用 Edge TTS 当前可用的 `ko-KR-SunHiNeural`，共 54 段，保存在 `audio/ko/beginner/`：

```powershell
python -X utf8 scripts/generate_audio.py --korean-beginner-validate-only
python -X utf8 scripts/generate_audio.py --korean-beginner-test
python -X utf8 scripts/generate_audio.py --korean-beginner-full
```

试听通过后运行完整模式；已有文件会自动跳过。单个假名及规则示范音请试听核对，尤其留意可能被语音服务当作助词处理的假名。

## 西班牙西语旅行认读教学音

西语教学音使用西班牙本土声音 `es-ES-ElviraNeural`，共 80 段，分别包含清晰词音、慢速短句和自然语速，保存在 `audio/es/beginner/`：

```powershell
python -X utf8 scripts/generate_audio.py --spanish-beginner-validate-only
python -X utf8 scripts/generate_audio.py --spanish-beginner-test
python -X utf8 scripts/generate_audio.py --spanish-beginner-full
```

试听模式会生成代表性的单词与短句样本；完整模式覆盖五元音、qu、gu、gü、r/rr、重音、连读和短句节奏。

## 俄罗斯俄语旅行认读教学音

俄语教学音使用 `ru-RU-SvetlanaNeural`，共 57 段，保存在 `audio/ru/beginner/`。音频文件由维护者按需运行脚本生成：

```powershell
python -X utf8 scripts/generate_audio.py --russian-beginner-validate-only
python -X utf8 scripts/generate_audio.py --russian-beginner-test
python -X utf8 scripts/generate_audio.py --russian-beginner-full
```

正式俄语词库与例句使用以下命令：

```powershell
python -X utf8 scripts/generate_audio.py --russian-validate-only
python -X utf8 scripts/generate_audio.py --russian-test
python -X utf8 scripts/generate_audio.py --russian-full
```

如果单个假名有杂音，可运行 `python -X utf8 scripts/generate_audio.py --beginner-repair`。它会为「い、ふ、ら、ん」各生成三个候选音，存入 `audio/ja/beginner/candidates/`；正式课程音频不会被覆盖。试听后选定清晰的版本，再替换对应正式文件并同步音频清单。

清单中的 `text` 是课程对应的假名；个别声音可使用 `synthesisText` 指定不同的合成输入。例如「い / イ」仍显示原字形，但目前用「い。」合成音频，以避开单字合成时的多余尾音。

该工具读取日语、英语、韩语、西班牙语与俄语五个内容包，分别为正式内容和辅助例句生成 MP3。教学音清单位于各语言的 `beginner/` 子目录。它不会修改语言包、`app.js` 或网页界面，也不需要 API Key。

## 1. 安装依赖

请在 `travel-vocab-v2` 项目目录打开终端，然后运行：

```powershell
python -m pip install -r scripts/requirements-audio.txt
```

`edge-tts` 使用在线语音服务，因此生成时需要联网。

## 2. 先检查词库

这一步不会联网，也不会生成文件：

```powershell
python scripts/generate_audio.py --validate-only
```

当前应检查到每个语言包 795 条正式内容和 230 条例句，且包内 ID 唯一。新增的 70 条三语例句由 `scripts/targeted_examples.json` 管理，筛选记录见 `例句筛选结果.md`。

只检查西班牙语包时可运行：

```powershell
python -X utf8 scripts/generate_audio.py --spanish-validate-only
```

## 3. 生成试听样本

```powershell
python scripts/generate_audio.py --test
```

试听模式为每个语言包处理前 5 条正式内容和前 2 条例句，五个语言包共生成 35 个目标。

- `audio/packs/jp-ja/entries/` 与 `examples/`
- `audio/packs/us-en/entries/` 与 `examples/`
- `audio/packs/kr-ko/entries/` 与 `examples/`
- `audio/es/` 与 `audio/packs/es-es/examples/`

如果只试听西班牙语，运行：

```powershell
python -X utf8 scripts/generate_audio.py --spanish-test
```

请先试听这些文件，确认音色和语速满意后再生成完整词库。

## 4. 只生成本次新增的例句音频

本次新增 70 个共享词义，四种语言共 280 条例句。运行以下命令只处理这些音频目标，不重做正式词条或旧例句：

```powershell
python -X utf8 scripts/generate_audio.py --targeted-examples-only
```

音频会写入 `audio/packs/{packId}/examples/`。已有且非空的文件会自动跳过。生成音频由项目维护者自行执行；本次内容更新仅完成音频路径与生成任务的准备。

### 西班牙语正式内容返工

西班牙语正式包的扩展短语和例句已改为人工审阅表。需要重建时运行：

```powershell
python -X utf8 scripts/generate_audio.py --spanish-refresh
```

该模式只生成 240 条扩展短语、1 条修正后的日期短句和 230 条例句，共 471 个目标；不会重做 475 条单词、其余固定短句或 `audio/es/beginner/` 中的 80 条零基础教学音。

## 5. 生成完整词库

```powershell
python scripts/generate_audio.py --full
```

当前完整模式校验 3975 条正式内容和 1150 条例句，共 5125 个音频目标。日英既有正式音频继续从 `audio/ja/` 与 `audio/en/` 原路径复用，其余内容按语言包路径写入。

只生成西班牙语正式内容与例句时运行：

```powershell
python -X utf8 scripts/generate_audio.py --spanish-full
```

西班牙语的 795 条正式内容保存在 `audio/es/`，230 条例句保存在 `audio/packs/es-es/examples/`。

```text
audio/packs/
├─ jp-ja/
│  ├─ entries/
│  └─ examples/
├─ us-en/
│  ├─ entries/
│  └─ examples/
└─ kr-ko/
   ├─ entries/
   └─ examples/
└─ es-es/
   └─ examples/
```

脚本会跳过已有且非空的 MP3，所以网络中断后可以直接重复运行。失败的词条会在最后集中列出；再次运行即可只补齐缺少的文件。

## 6. 更换声音和语速

打开 `scripts/generate_audio.py`，在文件顶部修改这些设置：

```python
JAPANESE_VOICE = "ja-JP-NanamiNeural"
ENGLISH_VOICE = "en-US-JennyNeural"
KOREAN_VOICE = "ko-KR-SunHiNeural"
SPANISH_VOICE = "es-ES-ElviraNeural"

RATE = "+0%"
VOLUME = "+0%"
PITCH = "+0Hz"
```

例如将 `RATE` 改为 `"-8%"` 可以让场景内容读得更慢。可用声音可以用以下命令查看：

```powershell
edge-tts --list-voices
```

选择日语声音时使用 `ja-JP-...Neural`，英语声音使用对应的 `en-US-...Neural`、`en-GB-...Neural` 等名称。
西班牙语言包应使用 `es-ES-...Neural`，不要换成 `es-MX` 或其他拉美地区声音。

## 解析与校验

语言包以 `window.registerContentPack({...})` 保存静态 JSON 数据。脚本不会执行其中的 JavaScript，而是提取并解析 JSON，检查正式内容数、例句数、ID 唯一性、朗读文字以及需要读音的语言是否完整。新增语言时需在脚本顶部配置对应语言包路径与合成声音。
